# Final Pool

This directory contains the final pool of **implemented tasks** from the BenchTasksCollv3 project.

Each task has been verified against the requirements in `tasks/examples`:
- `docs/task.md` — non-empty, all English
- `docs/agent_system_prompt.md` — non-empty, all English
- `docs/user_system_prompt.md` — optional, all English if present
- `task_config.json` — non-empty `needed_mcp_servers` and `needed_local_tools` (containing `claim_done`)

Tasks marked as **implementing** (e.g. those with Chinese content in docs or missing required files) are excluded from this pool.

All tasks here are marked **implemented** on the Notion Task Tracker page.
